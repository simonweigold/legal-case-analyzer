# Open Source AI Legal Assistance

## Origin

The original legal AI assistant was developed during the development phase of this project: https://cold.global and is available here: https://case-analyzer.cold.global. The original goal was to make legal case analysis in the field of private international law more efficient.

## Future

Now a bigger system is being built with a modular Interface and Backend. Integrate MCPs, Agent, bla bla blub

Why: openness supports security, reliability, etc.

Goal: automate analysis logics of legal processes that were originally hard manual labor. Now we want to create a platform for collecting best practices and coming up with structures for reliable automation procedures.
